# MediBridge AI — Public Healthcare Platform

MediBridge AI is a healthcare discovery platform designed to help users explore healthcare facilities and access relevant service information through a modern, user-friendly interface.

## Overview

The public-facing website focuses on making healthcare information easier to discover and navigate, with a responsive interface and multilingual support.

## Features

- **Healthcare Discovery** — Explore healthcare facilities and available services.
- **Search & Filtering** — Find relevant healthcare options more easily.
- **Bilingual Interface** — English and Persian (Farsi) language support.
- **Responsive Design** — Interface designed for different screen sizes.
- **Modern UI** — A clean, accessible healthcare technology experience.

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/rositabouyer-alt/medibridge-public-site.git
cd medibridge-public-site
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

Build the project for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

The production files are generated in the `dist/` directory.
